# Reference and naming research
Reviewed 2026-10-31. These sources inform the design; the resulting mockup is an original proposal.

## Windows visual direction
- [Microsoft: Title bar design](https://learn.microsoft.com/en-us/windows/apps/design/basics/titlebar-design): app identity, window controls, theme-aware chrome. The mockup uses the expanded 40px title bar; controls simulate a window inside the browser.
- [Microsoft: Color in Windows](https://learn.microsoft.com/en-us/windows/apps/design/signature-experiences/color): neutral light/dark surfaces with accent used sparingly for important controls and state. Graphite/iris is our chosen palette, not a Microsoft-prescribed palette.
- [Microsoft: NavigationView](https://learn.microsoft.com/en-us/windows/apps/design/controls/navigationview): familiar left navigation and compact behavior.
- [Microsoft: Modern app structure](https://learn.microsoft.com/en-us/windows/apps/develop/ui/windows-app-sdk-app-structure): integrated desktop structure.

## Workflow references
- [Laravel Herd for Windows](https://herd.laravel.com/windows): local project/runtime workflow.
- [OrbStack menu bar](https://docs.orbstack.dev/menu-bar): direct service access. Prior visual inspiration is secondary to Windows conventions in this revision.

## Palette decision
Graphite #1c1c20 and charcoal #242428 with iris #b8adff for the dark preview. Pearl #f8f8fa, white and darker iris #6550b5 for light mode.
Dark is shown for a low-light development session; light remains available for brighter workspaces. Neutral surfaces carry most of the interface. Violet indicates action/selection rather than coloring the whole application. The user explicitly dislikes the previous green direction.

## Name decision
**Aevrik**, pronounced “ey-vrik”, is the selected working proposal. Short, unusual spelling without the generic Dev/Stack/Local suffix. It is a coined brand proposal, not a claim about a foreign-language meaning.
Exact queries included `"Aevrik"` and `"Aevrik" software OR app OR github OR developer`. Results were principally personal names/accounts, such as [Letterboxd](https://letterboxd.com/aevrik/) and [Ajapaik](https://ajapaik.ee/photo/1171450/arhitekt-helje-aevrik/). No obvious developer application with the exact name was found in this limited search. This does not establish uniqueness, domain availability or trademark rights.

Rejected or less suitable candidates from this research:
- Nuvren: existing [web development studio](https://nuvren.com/).
- Velqen: existing [finance software](https://velqen.com/).
- Orvyn: several software/AI uses, including [Orvyn](https://orvynhq.com/).
- Veylun: existing [music identity](https://linktr.ee/veylun) plus token usage in search results.
- Auvren: existing [veterinary revenue platform](https://auvren.com/).
- Veltrix: existing [security developer tooling](https://www.veltrixsecops.com/documentations/installation-options.html).
- Rakit / Rakit Env: previous working name, existing [software organization](https://github.com/rakit).

Do not advertise the name as legally cleared or register anything based only on this screening.
